# 十岁啦 · 成长相册

一个在电视大屏上播放的十岁生日相册网站（方案 B 毛绒云朵）。从 0 岁到 10 岁每岁一张照片，中间穿插爸爸妈妈的三句心里话，最后吹蜡烛。界面中英双语，中文在上、英文在下。

纯静态网页，没有后端，也不需要构建：把 `birthday/` 整个文件夹放到哪里，哪里就能打开。它和本仓库里的 TrailMate 没有任何依赖关系，可以单独拷走。

## 打开方式

**推荐：在电脑上起一个本地服务，电脑用 HDMI 接电视。**

```bash
cd birthday
```

```bash
python3 -m http.server 8080
```

然后用 Chrome 或 Edge 打开 `http://localhost:8080`，按 `F` 全屏。

也可以直接双击 `index.html`，但浏览器每次都会重新询问摄像头权限。

| 页面 | 用途 |
| --- | --- |
| `index.html` | 播放相册 |
| `manage.html` | 导入照片、写寄语、选音乐、填名字和头像 |
| `login.html` | 连接相册服务器时的登录页 |
| `admin.html` | 管理员设置：短信验证开关、登录账号（连接相册服务器时） |

## 两种运行方式

| | 单机 | 连接相册服务器 |
| --- | --- | --- |
| 怎么开 | 上面的本地服务，或直接打开文件 | `node server/server.js`，见 `server/README.md` |
| 照片在哪 | 这台设备的这个浏览器里 | 服务器上，加密存放 |
| 多台设备 | 靠导出 / 导入相册包 | 自动同步，几秒内互相看到 |
| 登录 | 不需要 | 密码；新设备或换了国家时再加短信验证码 |
| 断网 | 可以播放 | 不行 |

网页会自己判断：由相册服务器提供时走服务器，否则走单机，不需要改任何设置。

需求和设计的完整说明见 `docs/tenup-requirements-design.html`（同目录有 Word 版）；每个界面的编号和截图见 `docs/screens.html`，网址后加 `?labels` 时页面角落会显示当前界面的编号。

## 章节与操作

开场选模式 → 礼物 → 相册 → 年龄 → 陪伴 → 许愿 → 年岁的名字。

| 按键 | 作用 |
| --- | --- |
| ← → | 开场时选模式；相册里翻照片；年岁页换一个名字 |
| ↓ | 相册里进入"这一年"的更多照片 |
| ↑ | 从"这一年"回到相册 |
| Enter / 遥控器 OK | 下一步 |
| Esc / 遥控器返回 | 上一章（在"这一年"里是回到相册） |
| F | 全屏 |
| M | 音乐静音 / 恢复 |
| 1–8 | 互动模式下模拟动作（笑、哭脸、挥手、比心、张开双手、握拳、举手、吹气），调试用 |

相册翻到最后一张再往后，就进入下一章。观看模式会自己往下播，停在许愿页等你按 OK 吹蜡烛。

## 互动模式（摄像头）

用的是**打开网页的这台电脑**的摄像头。画面只在本机浏览器里识别，不录像、不上传。右上角的小圆窗是孩子自己的镜像。

| 动作 | 效果 |
| --- | --- |
| 向左挥手（手从她的右边挥到左边） | 下一张照片；在其他章节是下一章 |
| 向右挥手 | 上一张照片 |
| 张开双手（两只手掌摊开，放在胸前） | 进入当年的相册，看这一年的更多照片 |
| 握个拳（单手） | 退出当年的相册，回到主相册 |
| 笑一笑 | 礼物页打开礼物；相册和年龄页撒彩带 |
| 装哭脸 | 兔子陪哭再抱抱 |
| 比个心（双手合成心形） | 送爱心 |
| 举高手（双手举过头） | 吹完蜡烛后放烟花 |
| 吹口气（嘟嘴） | 吹蜡烛 |

每一章屏幕底部只列出当前有用的动作。挥手是瞬间动作；其余动作要保持约 0.8 秒，提示条上的圆环会显示进度。

**挥手方向想反过来：** 把 `js/config.js` 里 `camera.swipe.invert` 改成 `true`。

**调灵敏度：** 网址后加 `?debug=1`，摄像头小窗下方会显示每个动作的实时分数（0–1）。对照着改 `js/config.js` 里的 `thresholds`，数字越小越容易触发；挥手的幅度在 `swipe.distance`。"装哭脸"最因人而异，建议让孩子本人试几次再定。

没有摄像头、拒绝授权或识别库加载失败时，会自动改为观看模式。

识别库和模型默认从网上加载（首次约 30 MB）。要完全离线：

```bash
sh tools/fetch-vendor.sh
```

然后把 `js/config.js` 里的 `camera.local` 改成 `true`。

## 照片

打开 `manage.html`：

- **封面**：每个年龄一张。把照片一次拖进来，会按顺序填进空着的年龄；拖到某一格上只替换那一岁。
- **这一年的更多照片**：每格下面的"+"可以再加最多 8 张，播放时张开双手（或按 ↓）进入查看。
- **拍照和录视频**：在手机和 iPad 上，照片管理页多出"拍照"、"录视频"、"从相册选"三个大按钮；点某一格的封面或"+"也会先问用相机还是相册。拍照、录视频直接打开后置相机，iPhone、iPad、安卓都一样。电脑上没有这些按钮，点一下直接选文件。
- **视频**：封面和更多照片都可以是视频。播放时，转到前面的视频自动播放，背景音乐暂时调小；观看模式等视频放完再翻到下一张。浏览器不允许带声音自动播放时，先静音播放，画面上出现"点一下听声音"。连接家庭服务器时每段视频最大 500 MB（可调），单机方式下最大 30 MB。
- **说明**：每个年龄一句中文（最多 12 字）和一句英文（最多 28 字符）。
- **寄语**：每张照片都可以配一句话（最多 40 字）、一段手写、一张小图，任意组合。封面点"寄语"按钮，更多照片点缩略图。播放时显示在照片旁边，手写会一笔一笔描出来。
- **背景音乐**：内置《生日快乐歌》和《摇篮曲》两段八音盒旋律，也可以上传自己的音频（单个不超过 20 MB）。"整部相册"和"吹完蜡烛之后"各选一首。请只上传你有权使用的音乐。
- **名字和头像**：孩子的中英文名字；"年龄"那一页上她、爸爸、妈妈的头像，没导入时显示图标占位。
- 单机方式下，照片保存在**这台设备的这个浏览器**里，不会上传。用同一台电脑、同一个浏览器播放，不需要再做别的。

要在另一台设备上播放，二选一：

1. 在 `manage.html` 点"导出相册包"，把下载到的 `album.js` 覆盖到 `album/album.js`。
2. 把照片放进 `album/` 文件夹：封面命名为 `0.jpg` … `10.jpg`，某一年的更多照片命名为 `3-1.jpg`、`3-2.jpg` …

读取顺序：本浏览器保存的 → `album/album.js` → `album/` 里的图片 → 占位图。

## 打印与导出

在 `manage.html` 底部点"打印与导出"（或打开 `print.html`）：

- **打印或存成 PDF**：相册排成一本书——封面、每岁一页（照片、说明、三个人的年龄、寄语）、这一年的更多照片、结尾页。可选 A4 或 Letter、横向或纵向、是否印更多照片和寄语、是否跳过还没有照片的年龄。要 PDF 就在打印窗口里选"存储为 PDF"，并勾选"背景图形"。
- **下载照片和视频（ZIP）**：每个年龄一个文件夹，里面是原图、原视频、手写寄语（SVG）和寄语配图，另有头像、上传的音乐和一份"相册说明"。

## 手机和 iPad

- **手机**：用浏览器打开网址后"添加到主屏幕"，会得到一个全屏打开的图标。主要用来上传和整理照片。
- **iPad 应用**：工程在 `ipad/`，推送后由 GitHub Actions 自动编译出未签名的安装包，签名和安装方法见 `ipad/README.md`。iPad 的前置摄像头可以做互动。

## 字体

字体文件在 `fonts/` 里，随网站一起打包，播放时不需要联网。正文里的中文用设备自带的中文字体。详见 `fonts/README.md`。

## 放到电视上

- **电脑接 HDMI**：最稳，摄像头互动用这种方式。
- **电视浏览器直接打开网址，或打包成应用**：整个文件夹是纯静态网页，带上相册包即可；没有摄像头时按观看模式播放。打包由你自己处理。

旧款电视卡顿时在网址后加 `?lowfx=1`，会关掉绒毛滤镜。
