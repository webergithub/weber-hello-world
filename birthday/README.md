# 十岁啦 · 成长相册

一个在电视大屏上播放的十岁生日相册网站（方案 B 毛绒云朵）。从 0 岁到 10 岁每岁一张照片，中间穿插爸爸妈妈的三句心里话，最后吹蜡烛。界面中英双语，中文在上、英文在下。

纯静态网页，没有后端，也不需要构建：把 `birthday/` 整个文件夹放到哪里，哪里就能打开。它和本仓库里的 TrailMate 没有任何依赖关系，可以单独拷走。

## 打开方式

**推荐：在电脑上起一个本地服务，电脑用 HDMI 接电视。**

```bash
cd birthday
```

```bash
python3 -m http.server 8080
```

然后用 Chrome 或 Edge 打开 `http://localhost:8080`，按 `F` 全屏。

也可以直接双击 `index.html`，但浏览器每次都会重新询问摄像头权限。

| 页面 | 用途 |
| --- | --- |
| `index.html` | 播放相册 |
| `manage.html` | 导入照片、填名字和说明 |

## 章节与操作

开场选模式 → 礼物 → 相册 → 年龄 → 陪伴 → 许愿。

| 按键 | 作用 |
| --- | --- |
| ← → | 开场时选模式，相册里翻页 |
| Enter / 遥控器 OK | 下一步 |
| Esc / 遥控器返回 | 上一章 |
| F | 全屏 |
| 1–6 | 互动模式下模拟动作（笑、哭脸、挥手、比心、举手、吹气），调试用 |

观看模式会自己往下播，停在许愿页等你按 OK 吹蜡烛。

## 互动模式（摄像头）

用的是**打开网页的这台电脑**的摄像头。画面只在本机浏览器里识别，不录像、不上传。右上角的小圆窗是孩子自己的镜像。

| 动作 | 礼物 | 相册 | 年龄 | 陪伴 | 许愿 |
| --- | --- | --- | --- | --- | --- |
| 笑一笑 | 打开礼物 | 撒彩带 | 撒彩带 | | 放烟花（吹完后） |
| 装哭脸 | | 兔子陪哭再抱抱 | | | |
| 挥挥手（张开手掌） | 翻开相册 | 下一张 | 下一章 | 去许愿 | 再看一遍 |
| 比个心（双手合成心形） | | 送爱心 | | 抱一抱 | |
| 举高手（双手举过头） | | 下一章 | | | |
| 吹口气（嘟嘴） | | | | | 吹蜡烛 |

动作要保持约 0.8 秒才触发，屏幕底部提示条上的圆环会显示进度。

**调灵敏度：** 网址后加 `?debug=1`，摄像头小窗下方会显示每个动作的实时分数（0–1）。对照着改 `js/config.js` 里的 `thresholds`，数字越小越容易触发。"装哭脸"最因人而异，建议让孩子本人试几次再定。

没有摄像头、拒绝授权或识别库加载失败时，会自动改为观看模式。

识别库和模型默认从网上加载（首次约 30 MB）。要完全离线：

```bash
sh tools/fetch-vendor.sh
```

然后把 `js/config.js` 里的 `camera.local` 改成 `true`。

## 照片

打开 `manage.html`：

- 把照片一次拖进来，会按顺序填进空着的年龄；拖到某一格上只替换那一岁。
- 每张可以填中文说明（最多 12 字）和英文说明（最多 28 字符），还可以填孩子的中英文名字。
- 照片保存在**这台设备的这个浏览器**里，不会上传。用同一台电脑、同一个浏览器播放，不需要再做别的。

要在另一台设备上播放，二选一：

1. 在 `manage.html` 点"导出相册包"，把下载到的 `album.js` 覆盖到 `album/album.js`。
2. 把照片命名为 `0.jpg` … `10.jpg` 放进 `album/` 文件夹。

读取顺序：本浏览器保存的 → `album/album.js` → `album/N.jpg` → 占位图。

## 放到三星电视上

- **电脑接 HDMI**：最稳，摄像头互动只有这种方式有。
- **电视浏览器直接打开网址**：需要先把这个文件夹部署到一个电视能访问的地址，并带上相册包。电视上通常没有摄像头，按观看模式播放。
- **装进电视**：三星电视是 Tizen 系统，装的是 `.wgt` 而不是 APK。用 Tizen Studio 新建 TV Web 项目，把本文件夹的内容和 `tizen/config.xml` 放进去打包。APK 只有外接 Android 电视盒时才用得上。

旧款电视卡顿时在网址后加 `?lowfx=1`，会关掉绒毛滤镜。

## 文件

| 路径 | 内容 |
| --- | --- |
| `js/config.js` | 称呼、播放节奏、摄像头灵敏度，改这里不用懂代码 |
| `js/app.js` | 章节流程、按键、动作对应的效果、三句心里话的文案 |
| `js/sense.js` | 摄像头识别 |
| `js/manage.js` | 照片管理 |
| `js/tenup.js`、`css/tenup.css`、`css/tokens.css` | 来自设计系统的组件、样式和颜色字体，不要手改 |
| `tools/sync-design.py` | 设计系统的 tokens.json 更新后重新生成 `css/tokens.css` |
