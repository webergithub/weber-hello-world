# PPT智能体 需求文档

| 项目 | 内容 |
|------|------|
| 产品 | PPT智能体（PPT Agent）——PPT / Word / PDF 智能解析、归档、检索与编排桌面工具 |
| 当前版本 | **v3.2.0**（2026-10-22） |
| 形态 | Windows x64 便携版 exe（Electron 44 + React 19），数据全部保存在本机 |

## 3. 运行环境与限制

- Windows 10/11 x64；exe 未签名，首次运行需在 SmartScreen 中选择“仍要运行”。
- 页面原样截图需要 PowerPoint 或 LibreOffice；未安装时使用内置版式渲染（近似预览）。
- 旧版 .ppt / .doc 需要 PowerPoint / Word 或 LibreOffice 转换。
- PDF 只提取文字层：扫描版（纯图片）PDF 没有可检索的文字（不做 OCR）；PDF 页面预览需要原文件仍在原位置。
- 大模型、语义向量为可选项；未配置时标签与查询扩展基于内置词表与 TF-IDF。
