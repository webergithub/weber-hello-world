# CityTwin 🏙🙈 —— 城市孪生躲猫猫

**CityTwin** 是一个纯前端的 **3D 模拟城市藏猫猫游戏**：n 个人藏，m 个人找。
躲藏者发布「不含任何地点信息」的线索和悬赏，寻找者在城市孪生世界里步行、骑共享单车、乘地铁/公交、打出租车，用信用点换取效率，靠听觉线索和雷达三角定位把躲藏者一个个揪出来。

## 🎮 乐趣在哪里

- **线索是"感官"的**：躲藏者只能描述听到/闻到/看到的环境——"每隔一阵子能听到浑厚悠扬的钟声"（大本钟附近！）、"河水拍岸和海鸥的叫声"、"咖啡和烘焙的香气"、"离我最近的建筑是砖红色的"。系统强制拦截地名、方位词和数字，藏得巧、写得妙才是本事
- **交通是策略**：走路免费但慢；地铁快但只走固定线路；出租车点哪去哪但按里程收费；预算有限，路线规划就是胜负手
- **雷达三角定位**：一次测距告诉你半径，两次测距画两个圆——交点就是猎物！花的是信用点，拼的是几何
- **拟真交通模拟**：列车/巴士沿真实线路加速、进站减速、停靠上客（站台上真的有小人排队上车）、关门发车；你可以和 NPC 乘客一起挤地铁
- **悬赏博弈**（好友模式）：藏得越刁钻，敢挂的悬赏越高；没被找到就把悬赏留在自己口袋
- **靠近的心跳感**：距离躲藏者 12 米内会听到窸窸窣窣的偷笑声，越近越响

## 📜 规则

- 找到一位躲藏者：**+50 基础信用点 + TA 的悬赏**
- 时限内找齐全部 → 寻找者大胜，剩余秒数折算奖励；否则未被发现的躲藏者获胜
- 好友模式（热座）：躲的人轮流上机飞行选点、写线索（自动校验，站名和地标名也在违禁词里）、设悬赏；找的人每 75 秒轮换

## 🚀 部署到自己的服务器

**方式 A · 服务器上拉取（最简单）**——SSH 登录服务器后一行命令：

```bash
curl -fsSL https://raw.githubusercontent.com/webergithub/weber-hello-world/claude/3d-hideandseek-game-8vw4y9/deploy/deploy-on-server.sh | bash
```

脚本会克隆/更新代码，检测 nginx 给出配置片段，或帮你用 `python3 -m http.server` 起静态服务（Oracle Cloud `opc` 用户记得在安全列表和 firewalld 放行端口）。

**方式 B · GitHub Actions 自动部署**——在仓库 Settings → Secrets 配置 `DEPLOY_HOST` / `DEPLOY_USER` / `DEPLOY_SSH_KEY` / `DEPLOY_PATH` 四个 secret，之后每次推送自动 rsync 到服务器（见 `.github/workflows/deploy.yml`）。

游戏是纯静态文件（`index.html` + `game.js` + `cities.js` + `lib/`），任何能托管静态文件的服务器都能跑，无后端依赖。

## 🎯 城市猎手玩法（PUBG 式交互）

- **跳跃**：`空格` 起跳，翻越花坛矮障
- **自由驾驶**：街边停着 6 辆车，`F` 上车——W/S 油门刹车、A/D 转向、撞墙减速，`F` 下车
- **门**：街边的门斗 `E` 开关——**不开门就看不到躲在门后的人**，躲藏者的新神位
- **景点探索**：首次抵达大本钟/伦敦眼等地标 +5💰 探索奖励（每城 6~10 处）
- **可进入建筑**：每城 6 间临街小店，走进门洞——柜台后是室内藏点，"有回声和暖光"的新线索
- **昼夜循环**：一局从白天打到黑夜，天黑后按 `L` 开手电筒，夜搜紧张感拉满
- **望远镜**：按住 `T` 变焦拉近，远距离侦察可疑角落；驾车可按 `H` 鸣笛
- **侦察无人机**：`G` 花 15💰 放飞，10 秒空中自由飞行俯瞰全城，倒计时结束自动返航
- **天气系统**：每局 40% 概率雨天——雨幕、雨声、闷雷、天色阴沉能见度降低、**地面雨滴涟漪**一圈圈扩散
- **手刹漂移**：驾驶中按住 `空格`——转向增益、车尾侧滑、轮胎摩擦声
- **街头行人**：每城 14 位路人沿人行道巡走，城市更有生活气
- **街头物资**（PUBG 拾取）：全城 16 处光柱物资点——💰信用点 / ⚡能量饮料（体力全满+短暂加速）/ 📡雷达芯片（下次雷达免费），走近自动拾取
- **空投补给**：开局约 1 分钟后降落伞补给箱从天而降，地图上橙色🪂脉冲标记，先到先得 +40💰 + 雷达芯片
- **罗盘方位条**：顶部中央 PUBG 式罗盘，随视角滚动显示 N/E/S/W 方位与刻度，黄色标记指向附近地标、橙色标记指向空投（不标记躲藏者，保留寻找乐趣）
- **脚印追踪**：每位躲藏者都留下一串走向藏点的脚印（左右交替步态）——**26 米内才随距离逐渐显形**，越近越清晰，配合窸窣声帮你锁定最后几米；远处完全看不见，不会破坏搜寻难度
- **抓捕特写**：抓到躲藏者的瞬间，镜头 1.2 秒环绕拉近聚焦目标，彩带庆祝后平滑切回
- **脚步声**：走路/奔跑有节奏不同的脚步声，左右脚音高交替（WebAudio 合成）

## ⌨️ 操作

- `WASD` 移动 · `Shift` 奔跑 · 按住鼠标拖动转视角 · 滚轮调镜头距离
- `E` 抓人/上下车 · `B` 借还单车 · `M` 打车地图 · `R` 雷达 · `V` 第一/第三人称 · `C` 收线索面板
- 右上角**小地图浮动窗口**可最小化/关闭（关闭后点 🗺 恢复）
- 躲藏阶段：`WASD` 飞行 · `空格` 上升 · `Z` 下降 · 点击青色光柱选藏点

## 🛠 技术

- Three.js r147（UMD，内置 `lib/three.min.js`）+ 单文件 `game.js`，无其他依赖
- 音效 WebAudio 实时合成；贴图 Canvas 程序化生成；建筑 InstancedMesh 批渲染
- 交通模拟：通用车辆系统（多段线寻路 + 加减速曲线 + 停站驻留 + NPC 上下客）
- `tools/bake-london.js`：公开地图数据 → 游戏坐标系烘焙管线（后续城市复用）
