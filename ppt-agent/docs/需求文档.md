## 2. 需求清单

状态说明：✅ 已实现　⚠️ 已实现但有限制（见备注）

### 2.1 文档解析（PARSE）

| 编号 | 需求 | 状态 | 实现与验收说明 |
|------|------|------|------|
| PARSE-01 | 对电脑上的 PPT 按页解析，内容转为 Markdown | ✅ | 逐页提取标题、正文层级、表格、图表（标题/系列/类别）、SmartArt、组合形状、隐藏页、分节；每页生成 Markdown，并按源目录结构镜像保存 `.md` |
| PARSE-02 | 解析备注中的讲解词 | ✅ | 每页“备注（讲解词）”单独存储、展示、检索 |
| PARSE-03 | 解析结果使用数据库归类存储 | ✅ | 本地 SQLite（node:sqlite，内置 FTS5 全文索引）；文件、页面、标签、向量、解析历史均入库 |
| PARSE-04 | PPT 中的视频只解析字幕，不解析视频本身 | ✅ | 只读 MP4 文本字幕轨（tx3g/wvtt）、PPT 隐藏式字幕部件（vtt/srt/ttml）、外链视频同名字幕；其他封装用 ffmpeg 仅提取字幕流 |
| PARSE-05 | 支持旧版 .ppt | ⚠️ | 需本机安装 PowerPoint 或 LibreOffice 转换后解析 |
| PARSE-06 | 增加 Word 文档的解析与检索（v1.1） | ✅ | .docx/.docm/.dotx 按标题分节（每节相当于一页），提取段落、列表、表格、图片说明与批注（作为“备注”）；旧版 .doc 经 Word 或 LibreOffice 转换 |
| PARSE-07 | 解析出的 Markdown 不放图片，只保留文字（v1.1） | ✅ | Markdown 中不插入图片引用，仅保留有意义的图片说明文字 |
| PARSE-08 | 每个 PPT 自动打 20 个标签，并按名称与内容归类 | ✅ | 中英领域概念 + TF-IDF 关键词 + 文件属性；可选大模型打标签；同时给出主题分类 |
| PARSE-09 | 识别黑底 / 白底 | ✅ | 背景继承（页面→版式→母版）、主题色、整页图片背景亮度；有截图时用截图边缘亮度校正 |

## 3. 运行环境与限制

- Windows 10/11 x64；exe 未签名，首次运行需在 SmartScreen 中选择“仍要运行”。
- 页面原样截图需要 PowerPoint 或 LibreOffice；未安装时使用内置版式渲染（近似预览）。
- 旧版 .ppt / .doc 需要 PowerPoint / Word 或 LibreOffice 转换。
- 大模型、语义向量为可选项；未配置时标签与查询扩展基于内置词表与 TF-IDF。
