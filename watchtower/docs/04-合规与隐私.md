# 合规与隐私（部署前必读）

> 本文是工程提示，不构成法律意见。正式项目（尤其涉及公共场所、员工、租户、访客的场景）
> 请咨询法务。

## 一、两部必须知道的法规

### 《公共安全视频图像信息系统管理条例》
国务院令第 799 号，**2025 年 4 月 1 日施行**，共 34 条。与本系统直接相关的要点：

| 要求 | 本项目怎么落地 |
| --- | --- |
| 采集的视频图像信息**保存不少于 30 日** | `privacy.retention_days` 默认 30；调低会破坏合规，代码里保留但请自行评估 |
| 用于公开传播且可能损害他人权益的，须对**人脸、车牌等敏感信息严格保护** | `privacy.blur_faces` 默认开；缩略图逐张打码，剪影成片可整体像素化 |
| 不得在可能泄露隐私的场所安装 | 系统不做也无法做这个判断——**装在哪里是你的责任** |

### 《人脸识别技术应用安全管理办法》
网信办 + 公安部，**2025 年 6 月 1 日施行**。要点：

| 要求 | 本项目怎么落地 |
| --- | --- |
| 人脸信息应当**存储于人脸识别设备内，不得通过互联网对外传输** | `face.local_only` 默认 true；人脸特征不进推送、不出公网 |
| 须取得**单独同意**（充分知情、自愿、明确） | 系统不替你取得同意——这是部署方的义务 |
| 有其他验证方式的，不得把人脸作为唯一验证方式 | 本项目不做人脸门禁，只做事后检索 |
| **宾馆客房、公共浴室、更衣室、卫生间等私密空间内禁止安装** | 硬性红线，系统无法代为判断 |
| 公共场所安装须设**显著提示标识** | 部署方义务 |

**所以本项目 `face.enabled` 默认 `false`。** 开之前请确认：你有合法依据、取得了单独同意、
并且人脸数据不出本地。

## 二、代码里已经落到的隐私默认值

| 配置 | 默认 | 含义 |
| --- | --- | --- |
| `face.enabled` | `false` | 人脸识别默认关 |
| `face.local_only` | `true` | 人脸特征只允许落本地库 |
| `privacy.blur_faces` | `true` | 缩略图/剪影对人脸打码 |
| `privacy.retention_days` | `30` | 事件与录像保留天数 |
| `api_token` | 空 | **空表示无鉴权**，启动时会打醒目警告 |
| `push.quiet_hours` | `23:00-07:00` | 夜间不响铃，只入库 |

### 打码不可用时会怎样

没装 opencv 时人脸检测不可用，`blur_faces_jpeg()` **原样返回图片并记一条警告，
计数返回 `-1`**——它不会假装打过码了。事件 `meta.faces_blurred == -1` 就是"未打码"的信号，
外发前请自行确认。

## 三、部署前自查清单

- [ ] 摄像头装在**自有场所**，且不在客房/浴室/更衣室/卫生间等私密空间内
- [ ] 公共区域已设置**显著的监控提示标识**
- [ ] 接入他人平台账号（萤石/乐橙/涂鸦/米家）已取得**账号所有者授权**
- [ ] `api_token` 已设置为足够长的随机串
- [ ] 服务**没有裸奔在公网**：走反向代理 + HTTPS，或只在 WireGuard/Tailscale 内网可达
- [ ] `retention_days` ≥ 30
- [ ] 若开启 `face.enabled`：已取得单独同意，且人脸数据不出本地
- [ ] 推送内容里**不包含**人脸特征、身份信息
- [ ] 明确了谁能访问查看端（令牌就是钥匙，发出去就收不回）

## 四、这个系统故意不做的事

保持克制本身就是一种设计：

- **不做身份识别与人员布控** —— 只回答"有人/几人/什么时候/往哪走"，不回答"是谁"。
- **不做行为判定** —— 不输出"可疑""徘徊意图"这类结论；剪影文案的系统提示词里
  明确要求"不臆测人物身份、动机，不做安全判断"。
- **不把原始视频传给第三方** —— 剪影解说只发送**统计数字与文字时间线**，
  不发送任何图像或视频帧。
- **不做人脸库自动积累** —— 即使开启人脸功能，也需要显式录入，不会看到谁就记住谁。

## 五、把数据交给谁

| 数据 | 去了哪里 | 可关闭 |
| --- | --- | --- |
| 视频流 | 摄像头 → 本机 go2rtc → 本机存储 | — |
| 事件、缩略图、剪影 | 只在本机存储目录 | — |
| 推送内容（标题/摘要/缩略图链接） | 你配置的通道（Bark/企微/钉钉/Telegram/自建） | `push.enabled=false` |
| 剪影解说的**统计与文字时间线** | Anthropic API（若开启 `digest.narrate` 且装了 SDK） | `digest.narrate=false` |
| 各平台账号凭证 | 只存本机 SQLite 的 `kv` 表 | — |
| 小米 P2P 建连的密钥协商 | 小米云（协议要求，绕不开） | 改用 `mode=micam` 或原生 RTSP |
