# 躲猫猫小镇 🏙🙈 (Hide & Seek City)

一个**纯前端 3D 模拟城市藏猫猫游戏**：n 个人藏，m 个人找。
躲藏者发布「不含任何地点信息」的线索和悬赏，寻找者在模拟城市里步行、骑共享单车、乘公交、打出租车，用信用点换取效率，把躲藏者一个个揪出来！

## 🚀 怎么玩

**直接双击打开 `index.html` 即可**（无需安装、无需服务器，Three.js 已内置在 `lib/` 中）。

也可以起个本地服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 🎮 两种模式

| 模式 | 玩法 |
|---|---|
| 🤖 快速游戏 | AI 躲藏者藏进城市各处，自动生成合法线索 + 悬赏，你（或多人轮流）来找 |
| 👥 好友同乐（热座） | 躲的玩家轮流上机：自由飞行俯瞰城市 → 点击青色光柱选藏身点 → 写线索（系统自动拦截地名/方位词/数字）→ 设置悬赏；然后把键盘交给寻找者，m 人每 75 秒轮换 |

## 📜 规则

- 每位躲藏者发布一条**线索**——只能描述环境感受（水声、钟声、饭菜香、建筑颜色……），**不允许包含任何地点信息**（地名、方位、数字都会被系统拒绝）
- 找到一位躲藏者：**+50 基础信用点 + 该躲藏者的悬赏**
- 时限内找齐全部躲藏者 → 寻找者大胜，剩余秒数折算成奖励；否则没被找到的躲藏者获胜

## 💰 信用点经济

| 行动 | 花费 | 说明 |
|---|---|---|
| 🚶 步行 / 奔跑 | 免费 | 奔跑消耗体力条 |
| 🚲 共享单车 | 8💰 | 在橙色单车站租借，速度 2.5 倍，随时还车 |
| 🚌 公交车 | 5💰 | 环线四站，到站时按 E 上下车 |
| 🚕 出租车 | 15💰 + 里程 | 打开地图点哪去哪 |
| 📡 雷达 | 12💰 | 显示最近躲藏者的距离，小地图画出测距圈——换个位置再测即可三角定位！ |

## ⌨️ 操作

- `W A S D` 移动，`Shift` 奔跑，按住鼠标拖动转视角，滚轮调节镜头距离
- `E` 抓人 / 上下公交　`B` 借还单车　`M` 打车地图　`R` 雷达　`V` 第一/第三人称　`C` 收起线索面板
- 躲藏阶段（好友模式）：`WASD` 飞行，`空格` 上升，`Z` 下降，点击青色光柱选点

## 🏙 城市里有什么

程序化生成的小镇：中央广场的**钟楼**（真的会整点敲钟，藏在附近的人会在线索里"听到钟声"）、带**湖泊与芦苇**的公园、老街**市场**、玻璃幕墙**高楼区**、堆着水泥管的**工地**、环线公交、川流不息的车流……每一局地图都不一样。

靠近躲藏者时会听到"窸窸窣窣"的声音，仔细听！🎧

## 🛠 技术

- Three.js r147（UMD 版内置于 `lib/three.min.js`，因此支持 `file://` 直接打开）
- 无任何其他依赖、无素材文件：音效全部由 WebAudio 实时合成，贴图由 Canvas 程序化生成
- `game.js` 单文件实现：城市生成 / 碰撞 / 交通系统 / 线索引擎 / 经济系统 / 热座流程
