How does joining face-to-face work?

When you create a room, the invite screen offers a Share button. On iPhone that opens the system share sheet including AirDrop; on Android it opens Nearby Share. Android Chrome can also write the invite to an NFC tag so another phone joins by tapping. All of these just carry the same room link.
