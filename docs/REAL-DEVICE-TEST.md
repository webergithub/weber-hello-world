# 真机互测清单 · 蓝牙自组网（iPhone ↔ 安卓）

在两台真手机上验证 TrailMate 的**跨平台蓝牙互通**：扫码进同队 → 营地互聊 / 跟车互见 / 离线记账 / 变声。
全程可**关掉蜂窝和 WiFi**，用来证明"无网也能互通"。

> ⚠️ **关键前提**：真实蓝牙跨设备互通**只有原生包（APK / IPA）支持**。
> Web PWA 版的「营地」是本机 `BroadcastChannel` 演示，两台手机的浏览器之间**不会**经蓝牙互通。
> 所以真机互测**必须装原生包**，别用网页版对拷。

---

## 0. 准备

- [ ] **装包**
  - 安卓：安装 `trailmate-android-apk`（CI 产物，debug 签名，允许"未知来源"直接装）
  - iPhone：安装 `trailmate-ios12-unsigned-ipa`（用 Sideloadly / AltStore 以免费 Apple ID 重签后装；支持 iOS 12.x～26.x）
  - 至少一台安卓 + 一台 iPhone；两台同类也可测同平台互通
- [ ] **开权限**
  - 蓝牙：两台都打开蓝牙开关
  - 安卓：授予"附近设备"（Android 12+）或"定位"（Android 11-）——BLE 扫描需要
  - iPhone：首次进「营地 / 跟车」时允许蓝牙权限
- [ ] **（可选）断网验证**：把两台都调飞行模式后**单独再开蓝牙**，用于证明无蜂窝/WiFi 也能互通
- [ ] **靠近**：两机相距 **< 10 米**（BLE 有效距离），先不隔墙

---

## 1. 扫码进同一队伍

| | |
|---|---|
| **步骤** | A 机：「队伍」→ 新建队伍，屏幕显示 6 位队伍码 + 二维码；B 机：「队伍」→ 扫码入队，对准 A 的二维码 |
| **预期** | 扫码后 B 的队伍码变得与 A 一致（如 `K7Q9ZP`） |
| **判定** | 两端「队伍」页显示相同队伍码 ✅ |

- [ ] 通过

> iPhone 生成的二维码安卓能扫、反之也能——两端用同一 `TM:CODE` 约定。

## 2. 营地蓝牙群聊（无网互通）

| | |
|---|---|
| **步骤** | 两机都进「营地」；A 发一条文字消息 |
| **预期** | B 在几秒内收到；营地页顶部"邻居"数 ≥ 1 |
| **判定** | B 收到 A 的消息气泡，昵称正确 ✅ |

- [ ] 通过

## 3. 多跳中继（三台，选测）

| | |
|---|---|
| **步骤** | A、C 拉开到互相收不到的距离，B 放中间；A 发消息 |
| **预期** | C 经 B 中继仍能收到（TTL 泛洪 + msgId 去重，最多 4 跳） |
| **判定** | C 收到 A 的消息，且不重复 ✅ |

- [ ] 通过（有三台设备时）

## 4. 跟车地图互见位置

| | |
|---|---|
| **步骤** | 两机都进「跟车」，允许定位；在室外/窗边等定位生效 |
| **预期** | 地图上除自己外，出现对方的标记（位置经蓝牙广播，每 3 秒刷新） |
| **判定** | 双方地图各自看到对方的头像标记 ✅ |

- [ ] 通过

## 5. 跨平台互通（iPhone ↔ 安卓）

| | |
|---|---|
| **步骤** | 一台 iPhone、一台安卓，扫码进同一队伍，重复第 2、4 项 |
| **预期** | iPhone 与安卓互聊、地图互见（同一 Service/Char UUID + 13 字节帧头协议） |
| **判定** | 跨平台消息与位置都能通 ✅ |

- [ ] 通过

## 排障

| 现象 | 处理 |
|---|---|
| 收不到消息 | 确认①两台蓝牙已开 ②同一队伍码 ③距离 < 10m ④安卓已授"附近设备/定位"权限 |
| 邻居数一直为 0 | 安卓重进「营地」页触发重新扫描；iPhone 确认已允许蓝牙权限 |
| iPhone 装不上 | 未签名 IPA 需 Sideloadly/AltStore 重签；证书 7 天过期后重签即可 |
| 地图无定位 | 到室外或窗边；确认已授定位权限（安卓需精确定位） |
| 隔墙/远距离断连 | BLE 约 10m，穿墙衰减大；用第三台居中做多跳接力（见第 3 项） |
| 想验证"真无网" | 两台飞行模式后单独开蓝牙，重测第 2、4 项 |

## 备注

- Web PWA 的「营地」仅本机 `BroadcastChannel` 演示，**不能**用于两台手机的真机互通验证——真机跨设备一律用原生包（APK / IPA）。
- 蓝牙线协议：Service UUID `7b2f9a10-4c3d-4b8e-9f21-0a1b2c3d4e5f`，13 字节帧头（8 msgId + 1 ttl + 2 seq + 2 total），MeshBus 信封 `[kind][teamLen][team][payload]`——iOS 与安卓完全一致，故可跨平台互通。
