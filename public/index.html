How does joining face-to-face work?

Same phone type — Android ↔ Android can 碰一碰 tap over NFC; iPhone ↔ iPhone can tap via AirDrop / proximity in the app.

iPhone ↔ Android — use the 4-digit face-to-face code the host reads out, or scan the QR. Both work across platforms, with no camera or NFC required for the 4-digit path.
